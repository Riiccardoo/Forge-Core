# EXP-000005: Hytale runtime common assets sent with setup-only progress after world join

## Problem

Joining an existing Zytale singleplayer world disconnects after entering Playing because WorldLoadProgress arrives late.

## Context

A large enabled fog area near the player is generated by Atmosphere Tool 1.3.1 after world join. The renderer invokes CommonAssetModule.sendAssetsToPlayer while the client is Playing; this built-in method inserts WorldLoadProgress between AssetInitialize and AssetPart. A prior successful log used Atmosphere Tool 1.3.0.

## Current Solution

Atmosphere Tool 1.3.2 replaces the setup-oriented sendAssetsToPlayer call with targeted runtime asset packets. The affected Hytale client entered the world without the prior WorldLoadProgress disconnect; generated fog animations still produced client parsing warnings recorded separately.

## Lessons

Other Hytale mods that stream generated CommonAsset files during Playing must avoid sendAssetsToPlayer because it emits a setup-only progress packet in Hytale 0.7.0; revalidate on future versions.
