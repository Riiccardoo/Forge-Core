# EXP-000002: Hytale scoped architectural repair with native multipart validation and isolated-save deployment

## Problem

Reconstruct an authorised monastic complex to architectural guides while preserving unrelated world data, original save and existing core mods. New asset pack and its enable are deliberate scoped configuration changes.

## Context

Blackridge reference-led replacement: 15 static custom model types, 60 persisted Adaptive Surface placements, 33 obsolete bed records explicitly removed, 8 new beds persisted. No Computer Use or native client screenshot validation.

## Current Solution

Build in a frozen full clone with the same enabled mods; verify actual models, fillers and rotations; apply previewed bounded edits; audit geometry and routes; reopen a native-record-merged deployment package before installing one verified region file.

## Lessons

The isolation, native-model inspection and scoped-diff method is reusable. IDs, bounds, rotations and native storage version must be revalidated on another world/build.
