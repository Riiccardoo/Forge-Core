The project owner selected All Rights Reserved. LICENSE.txt applies to original

This Java/UI project derives from the user's local Atmosphere Tool 2.1.0 and
the subsequent native editions. The historical baseline is preserved privately.
All active runtime source and the file-level provenance inventory are supplied
with the source package. Owner-provided historical source has not undergone an
independent contributor/chain-of-title audit; ownership is recorded as project
supplied, not inferred from successful tests.

Runtime materials:
- Original/project-supplied Java, native UI definitions and JSON configuration.
- Hytale Brush model/texture and TriggerVolume icon: references by ID only.
  Zero game image/model bytes are included.
- HytaleServer.jar-provided APIs, Gson and annotations: external runtime/build
  dependencies. Their implementations are not shaded or redistributed.
- No bitmap fog textures, shader source, DLL, client installer, extracted
  Hytale source, test component, world, private log or compiler is bundled.
- The original client/shader research and third-party native dependencies are
  excluded. Zones, Fullbright and original client-volume fog are archived
  separately; their archives are not public runtime or source-package payloads.

Platform scope:
This edition is a Java server plugin plus a normal UI/item asset pack. It does
not patch the client or bypass a client check. The Hytale EULA permits mods
subject to its conditions, including rights and no game-file redistribution.
CurseForge documents Java plugins installed as JARs. These are a documented
basis for this native format, not individual approval of this release.
Marketplace moderation, actual in-game-browser delivery and future Hytale
compatibility remain outside the completed technical tests.
