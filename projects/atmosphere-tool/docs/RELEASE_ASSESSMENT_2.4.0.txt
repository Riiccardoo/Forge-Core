ATMOSPHERE TOOL NATIVE 2.4.0 - RELEASE ASSESSMENT
Date: 2026-10-29
Target: Windows, Java 25, Hytale server 0.7.4
Prepared for submission; no marketplace upload or GitHub Release performed.

DECISION
Manual native installation: technically verified. No client patch/installer.
CurseForge: correct native plugin JAR format; submission and moderation NOT RUN.
In-game browser: native format, but actual availability and delivery NOT VERIFIED.
Final 2.4.0 three-tab client layout: NOT RUN. The complete 2.3.1 visual result
was accepted by the user; that is historical feedback, not a new 2.4.0 test.
This is a release package with explicit remaining checks, not unconditional
platform/legal approval. Do not describe an untested future Hytale release as
compatible or remove the =0.7.4 guard without validation.

CHANGES AND PRESERVATION
Zones UI, area commands, selection listeners, polling, zone repositories and
per-player overrides are removed. All zone files remain dormant and unchanged.
Global Fullbright and the original client-volume edition remain archived.
No DLL, client installer, shaders or old archives are included in runtime.
Global fog, presets, brightness, manual lunar transparency, sky controls, exact
numeric input and global-only custom saves remain. No change to save format 2.
47 freshly recompiled production class payloads match the final JAR byte for
byte. Twelve class payloads for approved fog brightness, lunar transparency,
sky orbit, snapshots, custom library, persistence, native fog and migration
also match 2.3.1 exactly. Main service wiring changes only remove zone handling.

PERFORMANCE (MEASURED, NOT AN FPS CLAIM)
Runtime JAR: 141,733 -> 93,247 bytes (34.2% smaller).
Plugin setup median: 25.537 -> 21.093 ms (17.4% lower in this sample).
Three separate JVM samples per version, alternating order, same isolated
existing world and settings, warm OS filesystem cache. Baseline only adds
the same setup timer/logger; its other JAR entries are unchanged. Empty v1 zone
fixture exercises the old version's normal backup. Candidate leaves it unread.
Baseline range 24.826-31.271 ms; candidate range 20.764-24.406 ms.
End-to-end server process time including shutdown ranges 8.174-8.614 seconds;
no demonstrated improvement in whole-server load time. Small sample, one PC.
Removed 100 ms zone polling and 500 ms selection polling; no active zone
selection packet listeners. The remaining weather writer is edit-driven.
Server edit-to-registered-weather: 20 samples, p50 100.509 ms, p95 104.570 ms.
Brightness: 20 samples p50 101.519 ms, p95 137.372 ms.
Moon transparency: 7 samples p50 101.176 ms, p95 134.363 ms, includes a no-op.
These exclude client display/GPU/network and are not low-end-hardware results.
No new renderer, texture upload or generated volume is present.
